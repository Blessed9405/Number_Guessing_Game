# Number Guessing Game

A simple Python terminal game where the player tries to guess a secret number between 1 and 20. You have 3 lives to guess correctly before the game ends.

## How to Play

1. Run the game.
2. Enter a number from 1 to 20.
3. If the guess is wrong, you lose one life.
4. Keep guessing until you either:
   - guess the correct number and win, or
   - run out of lives and lose.
5. Enter `0` at any time to exit the game.

## Requirements

- Python 3.x

## Run the Game

```bash
python app.py
```

## Example

```text
Lives: 3
Enter any number from 1 to 20 ('0' to exit): 10
Sorry.Try again

Lives: 2
Enter any number from 1 to 20 ('0' to exit): 3
Correct.You have won!
```
